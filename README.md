## 작업 방식

팀 작업 규칙(브랜치, 커밋, PR, 리뷰·머지 흐름)은 [CLAUDE.md](CLAUDE.md)에 있다. 모든 팀원의 Claude가 세션을 시작할 때 이 파일을 읽는다.

PR을 만들 때는 [PR 템플릿](.github/pull_request_template.md)의 항목을 모두 채운다.
