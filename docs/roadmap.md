## 5. 출시 준비 (행정·운영)

현동훈이 진행하고, 단계마다 Claude가 필요한 서류와 절차를 구체적으로 돕는다. 각 절차의 요건은 진행할 때 최신 정보로 다시 확인한다.

| 상태 | 할 일 | 메모 |
| --- | --- | --- |
| ⬜ | 서비스 이름 확정 → 상표 출원 | 다음 회의. 이름이 바뀌면 아래 "이름 변경"을 먼저 한다 |
| ⬜ | 사업자 등록, 사업자 계좌 | PG 계약과 알림톡의 전제 |
| ⬜ | 세무사 상담: 결제 수수료·쿠폰의 부가세 처리 | 사업자 등록 때, 공급자 약관 확정 전. 업주에게 받는 결제 수수료(판매가의 N%)와 줍줍이 부담하는 쿠폰(매출 에누리인지 판촉비인지)을 어떻게 신고하는지 확인한다 |
| ⬜ | 정산 지급 구조 확정 + 법률 확인 | 추천: PG 지급대행(토스페이먼츠가 업주에게 바로 지급, 줍줍은 수수료만). 줍줍 계좌로 받아 나눠 주는 방식은 전자금융거래법상 등록 문제가 생길 수 있다 |
| ⬜ | PG 실제 계약 (포트원 + 토스페이먼츠, 지급대행 포함) | 실제 PG 수수료율이 여기서 정해진다. 지급대행은 업주(셀러) 등록·심사가 필요하다 |
| ⬜ | 통신판매업 신고 | 사업자 등록 후 |
| ⬜ | 위치기반서비스사업 신고 | 사업자 등록 후, 고객 위치를 쓰는 기능(내 주변 매물·지도)을 실제 고객에게 열기 전. 위치정보법에 따른 신고이고, 위치정보 이용 동의(C-104)와 개인정보 처리방침에 위치정보 항목을 같이 준비한다 |
| ⬜ | 약관 초안(이용약관, 개인정보 처리방침, 위치정보 동의, 공급자 약관) → 법률 검토 | 초안은 현동훈이 Claude와 쓴다 |
| ⬜ | 카카오톡 채널 비즈니스 인증 → 알림톡 | 사업자 등록 후 |
| ⬜ | 운영용 Supabase, 도메인, Vercel Pro, 로그인 서비스 운영 전환·검수 | 출시 직전 |
| ⬜ | 외부 서비스 계정을 개인 계정에서 줍줍 계정으로 이전 | 사업화 때 |
