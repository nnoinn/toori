# 로드맵

전체 작업이 어떤 순서로 가는지, **누가 무엇을 기다리는지**를 보여주는 문서다. nnoinn(현동훈)의 Claude가 관리하고, 작업이 끝나거나 새 일·결정이 생기면 PR로 갱신한다. 팀원은 직접 고치지 않는다.

- 각자 작업의 자세한 순서는 로드맵 Issue에 있다: 강규민 #15(W1~), 정찬형 #19(J0~), 정민석 #23(O1~)
- 결정된 것과 남은 결정은 [tech-guide.md](tech-guide.md) "7. 결정 필요 목록"에 있다
- 표시: ✅ 끝남 · ⏳ 진행 중 · ⬜ 아직 · 🔒 앞 단계를 기다림

## 지금 위치 (2026-10-27)

**2. 1단계 진행 중.** 10/23부터 전원 개발 중이다. 진짜 카카오·구글 로그인(W2 ①, #101)과 고객 가입 저장(W2 ②, #104), 입점 승인 상태(#105)·신규 고객 판별(#106) 함수가 들어왔다. 지금 여러 사람이 기다리는 것은 정찬형의 로그인 화면 버튼 연결(그래야 모두 로그인해서 시나리오 명령으로 확인할 수 있다)과 강규민의 개발 DB 마이그레이션 0004 적용(그래야 `/join` 가입이 저장된다)이다.
