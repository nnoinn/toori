전체 작업이 어떤 순서로 가는지, **누가 무엇을 기다리는지**를 보여주는 문서다. nnoinn(현동훈)의 Claude가 관리하고, 작업이 끝나거나 새 일·결정이 생기면 PR로 갱신한다. 팀원은 직접 고치지 않는다.

## 지금 위치 (2026-11-01)

**2. 1단계 끝 무렵, 2단계 진행 중.** 운영자 입점 승인 화면(A-101, #157)이 들어와서 가입 → 승인 → 매물 등록이 이어졌다. 원장님은 가입·입점 상태·사업자 정보·정산 계좌·대시보드(#160)·매물 수정·마감(#169)까지, 고객은 내 정보·예약 확인·결제 결과·예약 취소(#137, #139, #140, #162)와 포트원 결제창(#168)·예약 완료 화면(#179)까지 들어왔다. **결제창 → 포트원 확인 → 예약 확정이 처음으로 진짜로 이어졌다(테스트 모드, #155).** 확정하지 못한 결제는 자동으로 취소된다(W12, #196·#197, 예약 작업 10분마다). 고객 홈은 매물 목록·찜한 샵 매물·지도 중 골라 들어가는 구조가 됐다(#241). 고객 예약 취소가 포트원 부분 환불까지 진짜로 이어진다(W14, #222, 테스트 모드). 11/8에 예약 확정 웹 푸시(W16 첫 단계, #257), 운영자 회원 조회(#258), 예약번호 숫자 12자리(#264), 예정 예약 상세의 방문 확인 칸(#261)이 들어왔다. 다음은 강규민의 포트원 웹훅(W13, #248 수정 중)이다.
