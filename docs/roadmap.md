# 로드맵

전체 작업이 어떤 순서로 가는지, **누가 무엇을 기다리는지**를 보여주는 문서다. nnoinn(현동훈)의 Claude가 관리하고, 작업이 끝나거나 새 일·결정이 생기면 PR로 갱신한다. 팀원은 직접 고치지 않는다.

- 각자 작업의 자세한 순서는 로드맵 Issue에 있다: 강규민 #15(W1~), 정찬형 #19(J0~), 정민석 #23(O1~)
- 결정된 것과 남은 결정은 [tech-guide.md](tech-guide.md) "7. 결정 필요 목록"에 있다
- 표시: ✅ 끝남 · ⏳ 진행 중 · ⬜ 아직 · 🔒 앞 단계를 기다림

## 지금 위치 (2026-11-01)

**2. 1단계 끝 무렵, 2단계 진행 중.** 운영자 입점 승인 화면(A-101, #157)이 들어와서 가입 → 승인 → 매물 등록이 이어졌다. 원장님은 가입·입점 상태·사업자 정보·정산 계좌·대시보드(#160)·매물 수정·마감(#169)까지, 고객은 내 정보·예약 확인·결제 결과·예약 취소(#137, #139, #140, #162)와 포트원 결제창(#168)·예약 완료 화면(#179)까지 들어왔다. **결제창 → 포트원 확인 → 예약 확정이 처음으로 진짜로 이어졌다(테스트 모드, #155).** 다음은 강규민의 자동 취소(W12)다. 자동 취소 전까지는 확정 못 한 결제가 취소되지 않고 주문에 기록만 남는다.
