# 투리 약관·동의 문구 초안

> **법률 검토 전 초안이다. 앱·사이트·카카오톡 채널에 그대로 게시하지 않는다.**
> 법률 검토 뒤 확정본으로 바꾸고, 그때 정책값 `TERMS_VERSIONS`(`src/server/policy/terms.ts`)의 버전 값을 바꾼다.

## 원칙

- 우리 서비스 규칙(CLAUDE.md "핵심 비즈니스 규칙", `src/server/policy/`)과 숫자가 같아야 한다. 정책값을 바꾸면 이 문서도 같이 고친다
- 투리는 **통신판매중개자**다. 서비스(시술) 계약의 당사자는 원장님이고, 투리는 매물을 올리고 예약·결제를 중개한다
- 공정거래위원회 표준약관(전자상거래)과 개인정보보호위원회 처리방침 작성지침의 구조를 따르되, 우리 서비스에 맞게 줄이고 고쳤다
- `[검토 필요]`는 법률 검토에서 확인할 곳이다. 질문은 [법률 검토 질문](legal-review-questions.md)에 모았다

## 채울 빈칸

공개 레포라 사람을 알아볼 수 있는 값은 여기에 쓰지 않는다. 확정본을 만들 때 채운다.

| 빈칸 | 언제 정해지나 |
| --- | --- |
| `{운영자}`, `{대표자}`, `{사업자등록번호}`, `{통신판매업 신고번호}`, `{주소}` | 사업자 등록·통신판매업 신고 뒤 |
| `{고객센터 연락처}`, `{이메일}` | 운영용 연락처를 만들 때 |
| `{개인정보 보호책임자}`, `{위치정보관리책임자}` | 출시 전 지정 |
| `{결제 수수료율}` | PG 계약 뒤(`PAYMENT_FEE_RATE`) |
| `{정산 주기}` | 2단계 전(기술 가이드 7장) |
| `{PG사}` | PG 계약 뒤(포트원 + 토스페이먼츠 예정) |
| `{시행일}` | 출시 전 |

## 고칠 때

- 문서를 고치면 맨 아래 변경 기록에 날짜와 무엇을 바꿨는지 적는다
- 화면에 들어가는 문구(가입·결제 동의 등)는 [동의 문구 모음](consent-texts.md)을 기준으로 정찬형·정민석이 화면에 넣는다. 그 전에는 임시 문구를 쓴다
