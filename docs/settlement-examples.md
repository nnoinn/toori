# 정산 계산 예시

결제할 때 돈이 어떻게 나뉘는지, 원장님 정산액과 투리 몫을 어떻게 계산하는지 숫자로 보여주는 문서다. 규칙은 CLAUDE.md "핵심 비즈니스 규칙"과 [tech-guide.md](tech-guide.md) X-205가 기준이다. 이 문서의 예시는 정산 함수(X-205, 강규민 W8)의 테스트 기댓값으로 그대로 쓸 수 있다.

## 1. 돈이 오가는 순서

투리는 고객 돈을 직접 받거나 보내지 않는다. 돈은 처음부터 끝까지 PG(토스페이먼츠)가 맡고, 투리는 "누구에게 얼마"를 계산해서 알려준다(PG 지급대행).

1. **고객 결제:** 고객이 카드로 결제한다. 쿠폰을 쓰면 쿠폰만큼 덜 낸다. 쿠폰은 카드로 오간 돈이 아니라서 PG는 쿠폰을 모른다
2. **PG 수수료:** PG는 카드로 실제 결제된 금액에만 수수료를 떼고, 나머지를 맡아 둔다. PG 수수료는 PG와 계약한 투리의 비용이다
3. **원장님 지급:** 투리가 원장님 몫을 계산해 PG에 알려주면, PG가 원장님 계좌로 바로 보낸다
4. **투리 몫:** PG가 맡아 둔 돈에서 원장님 몫을 보내고 남은 돈이 투리 몫이다. 한 거래에서 모자라면 다른 거래에서 남은 투리 몫으로 메운다

## 2. 용어와 계산식

| 용어 | 뜻 |
| --- | --- |
| 판매가 | 할인가. 정가 × (1 − 할인율). 쿠폰을 빼기 전 금액 |
| 플랫폼 수수료 | 투리의 중개 수수료. **오픈 기간에는 0%**(3장). 법인 전환 뒤에는 판매가 × 할인율별 수수료율(10%→10%, 20%→9%, 30%→8%, 40%→7%, 50%→6%), VAT 별도(4장) |
| 결제 수수료 | 투리의 결제·정산 처리 대가. 판매가 × N%(결제 수단과 상관없이 한 비율, PG 계약 후 실제 PG 비용을 덮는 수준으로 정한다), VAT 별도. 실제 PG 비용과 같을 필요는 없다 |
| 실제 PG 수수료 | PG가 카드 결제액에서 떼는 돈. 투리의 비용이고, 원장님 정산에는 쓰지 않는다 |
| 쿠폰 | 투리가 고객 대신 낸 돈. 비용은 투리 몫에서 정리한다 |

- **원장님 정산액** = 기준 금액 − 플랫폼 수수료 − 그 VAT − 결제 수수료 − 그 VAT − 원장님 귀책 취소 패널티(있을 때만)
- **기준 금액:** 이용 완료·노쇼 = 판매가, 고객 취소 = 판매가 × 위약금 비율, 원장님 귀책 취소 = 0
- **투리 손익(부가세 제외)** = 플랫폼 수수료 + 결제 수수료 − 실제 PG 수수료 − 쿠폰 부담분
- 모든 수수료와 VAT는 원 미만을 버린다
- 고객에게는 어떤 결제 수수료도 붙이지 않는다(카드 수수료를 고객에게 넘기는 것은 여신전문금융업법 위반)

## 3. 오픈 기간 예시 (지금 적용: 플랫폼 수수료 0%)

**오픈 기간에는 플랫폼 수수료를 받지 않고 결제 수수료만 받는다(10/14 결정).** 사용자를 모으는 데 집중하고 투리 이익은 0원 근처로 둔다. 할인율별 플랫폼 수수료는 4장에 보관해 두고, 법인으로 전환하면서 공급자 약관을 바꿀 때 적용한다.

**가정:** 4장과 같다. 정가 50,000원, 쿠폰 3,000원, 실제 PG 수수료 3.0% + VAT, 결제 수수료 N 3.0%(VAT 별도). 둘 다 PG 계약 전 임시 숫자다.

| 항목 | 10% 할인, 쿠폰 없음 | 10% 할인, 쿠폰 3,000원 | 50% 할인, 쿠폰 없음 | 50% 할인, 쿠폰 3,000원 |
| --- | ---: | ---: | ---: | ---: |
| 판매가 | 45,000 | 45,000 | 25,000 | 25,000 |
| ① 고객 카드 결제 | 45,000 | 42,000 | 25,000 | 22,000 |
| ② 실제 PG 수수료 + VAT | 1,350 + 135 | 1,260 + 126 | 750 + 75 | 660 + 66 |
| PG가 맡아 둔 돈 | 43,515 | 40,614 | 24,175 | 21,274 |
| 플랫폼 수수료 | 0 | 0 | 0 | 0 |
| 결제 수수료 + VAT | 1,350 + 135 | 1,350 + 135 | 750 + 75 | 750 + 75 |
| ③ 원장님 정산 | **43,515** | **43,515** | **24,175** | **24,175** |
| 원장님 정산 / 정가 | 87.0% | 87.0% | 48.4% | 48.4% |
| ④ 투리에 남는 돈 | 0 | −2,901 | 0 | −2,901 |
| 투리 손익(부가세 제외) | **0** | **−2,910** | **0** | **−2,910** |

### 오픈 기간, 고객이 30시간 전에 취소한 경우 (위약금 30%, 10% 할인 매물)

| 항목 | 쿠폰 없음 | 쿠폰 3,000원 |
| --- | ---: | ---: |
| 고객 카드 결제 | 45,000 | 42,000 |
| 고객 환불(카드 결제액 × 70%) | 31,500 | 29,400 |
| 카드에 남은 돈 | 13,500 | 12,600 |
| 실제 PG 수수료 + VAT(남은 돈 기준) | 405 + 40 | 378 + 37 |
| PG가 맡아 둔 돈 | 13,055 | 12,185 |
| 기준 금액(판매가 × 30%) | 13,500 | 13,500 |
| 플랫폼 수수료 / 결제 수수료 + VAT | 0 / 405 + 40 | 0 / 405 + 40 |
| 원장님 정산 | **13,055** | **13,055** |
| 투리에 남는 돈 | 0 | −870 |
| 투리 손익(부가세 제외) | **0** | **−873** |

- 결제 수수료 N을 실제 PG 수수료율과 같게 잡으면, 쿠폰 없는 거래의 투리 손익은 0원이다. N이 실제 PG 수수료율보다 높으면 그 차이만큼 남는다
- 쿠폰 비용(1장에 약 2,910원)은 투리가 진다. 지금 쿠폰은 원장님 귀책 보상 쿠폰뿐이고, 그때 걷는 패널티 5,000원이 덮는다
- **오픈 기간에는 다른 거래에서 남는 돈이 거의 없다.** 쿠폰 거래처럼 PG가 맡아 둔 돈보다 원장님 몫이 큰 거래는, 원장님 귀책 패널티를 걷은 돈(그 원장님 정산에서 뺀 만큼 PG에 남는다)으로 메운다. 패널티를 아직 못 걷었거나 미수일 때 부족분을 채우는 방법은 PG 계약 때 확인한다

## 4. 법인 전환 뒤 예시 (할인율별 플랫폼 수수료, 보관)

지금은 적용하지 않는다. 법인으로 전환하면서 공급자 약관을 바꿀 때 적용할 모델이다.

**가정:** 정가 50,000원, 쿠폰 3,000원. 실제 PG 수수료는 카드 결제액의 3.0% + VAT, 결제 수수료 N은 3.0%(VAT 별도)로 가정했다. 둘 다 PG 계약 전 임시 숫자다.

| 항목 | 10% 할인, 쿠폰 없음 | 10% 할인, 쿠폰 3,000원 | 50% 할인, 쿠폰 없음 | 50% 할인, 쿠폰 3,000원 |
| --- | ---: | ---: | ---: | ---: |
| 판매가 | 45,000 | 45,000 | 25,000 | 25,000 |
| ① 고객 카드 결제 | 45,000 | 42,000 | 25,000 | 22,000 |
| ② 실제 PG 수수료 + VAT | 1,350 + 135 | 1,260 + 126 | 750 + 75 | 660 + 66 |
| PG가 맡아 둔 돈 | 43,515 | 40,614 | 24,175 | 21,274 |
| 플랫폼 수수료 + VAT | 4,500 + 450 (10%) | 4,500 + 450 (10%) | 1,500 + 150 (6%) | 1,500 + 150 (6%) |
| 결제 수수료 + VAT | 1,350 + 135 | 1,350 + 135 | 750 + 75 | 750 + 75 |
| ③ 원장님 정산 | **38,565** | **38,565** | **22,525** | **22,525** |
| 원장님 정산 / 정가 | 77.1% | 77.1% | 45.1% | 45.1% |
| ④ 투리에 남는 돈 | 4,950 | 2,049 | 1,650 | −1,251 |
| 투리 손익(부가세 제외) | **4,500** | **1,590** | **1,500** | **−1,410** |

- 투리에 남는 돈(④)에는 국세청에 낼 부가세가 섞여 있다. 플랫폼 수수료 VAT + 결제 수수료 VAT − PG에 낸 VAT를 빼면 투리 손익이 된다
- 쿠폰 거래의 투리 손익 = 플랫폼 수수료 + 결제 수수료 − 실제 PG 수수료 − 쿠폰. 예: 4,500 + 1,350 − 1,260 − 3,000 = 1,590
- 쿠폰의 부가세 처리(매출 에누리인지 판촉비인지)는 세무사 확인 전이라 위 손익에 반영하지 않았다

### 고객이 30시간 전에 취소한 경우 (위약금 30%, 10% 할인 매물)

| 항목 | 쿠폰 없음 | 쿠폰 3,000원 |
| --- | ---: | ---: |
| 고객 카드 결제 | 45,000 | 42,000 |
| 고객 환불(카드 결제액 × 70%) | 31,500 | 29,400 |
| 카드에 남은 돈 | 13,500 | 12,600 |
| 실제 PG 수수료 + VAT(남은 돈 기준) | 405 + 40 | 378 + 37 |
| PG가 맡아 둔 돈 | 13,055 | 12,185 |
| 기준 금액(판매가 × 30%) | 13,500 | 13,500 |
| 플랫폼 수수료 + VAT / 결제 수수료 + VAT | 1,350 + 135 / 405 + 40 | 1,350 + 135 / 405 + 40 |
| 원장님 정산 | **11,570** | **11,570** |
| 투리에 남는 돈 | 1,485 | 615 |
| 투리 손익(부가세 제외) | **1,350** | **477** |

- 쿠폰을 쓴 고객은 쿠폰을 돌려받지 못하고, 환불은 카드 결제액 기준이다. 원장님 위약금은 쿠폰과 상관없이 판매가 기준이라 같다
- 쿠폰 거래에서는 기준 금액(13,500)과 카드에 남은 돈(12,600)의 차이 900원을 투리가 메운다

## 5. 정리

- **오픈 기간(지금):** 플랫폼 수수료가 0%라서, 결제 수수료를 실제 PG 비용만큼 받으면 쿠폰 없는 거래의 투리 손익은 0원이다. 원장님은 정가의 87.0%(10% 할인), 48.4%(50% 할인)를 받는다
- **원장님이 받는 돈은 쿠폰과 상관없이 같다.** 정산은 판매가 기준이다
- **법인 전환 뒤에는, 결제 수수료를 실제 PG 비용만큼 받으면 쿠폰 없는 거래에서 투리 손익은 플랫폼 수수료와 같다**(10% 할인 4,500원, 50% 할인 1,500원). 결제 수수료를 안 받으면 PG 비용만큼 투리 손익이 줄어든다
- **쿠폰 비용은 투리가 진다.** 쿠폰 때문에 PG 수수료가 덜 나간 만큼(3,000원의 3.0%)은 투리에게 돌아온다
- **쿠폰 1장의 투리 비용은 할인율과 상관없이 약 2,910원이다**(3,000원 − 쿠폰 때문에 덜 나간 PG 수수료 90원). 50% 할인 매물처럼 그 거래의 투리 수익이 작으면 거래 하나만 보면 손해(−1,410원)로 보인다. 지금 쿠폰은 원장님 귀책 취소 보상 쿠폰뿐이고, 그때 걷는 패널티 5,000원이 쿠폰 비용을 덮으므로 사용 조건은 두지 않는다(10/12). 패널티를 못 걷으면(미수) 쿠폰 비용만 남는다. 패널티 없이 나가는 초대 쿠폰(C-701, P2)을 만들 때는 사용 조건을 다시 정한다
- 한 거래에서 PG가 맡아 둔 돈보다 원장님 몫이 크면(50% 할인 + 쿠폰) 다른 거래에서 남은 투리 몫으로 메운다. 토스페이먼츠는 확정된 잔액 안에서만 지급을 요청할 수 있으니, 잔액이 모자랄 때 채우는 방법을 PG 계약 때 확인한다
