# 팀 공지

nnoinn이 팀원에게 알릴 내용을 PR과 함께 이 파일에 추가한다. **새 공지는 맨 위에** 쓴다.
팀원의 Claude는 세션을 시작할 때 새로 추가된 공지를 자동으로 읽고 요약해서 알려준다(`scripts/session-start.mjs`).

형식:

```text
## YYYY-MM-DD · 대상(전원 또는 이름)
- 무엇이 바뀌었나
- 할 일: 팀원이 해야 할 것 (없으면 "없음")
```

---

## 2026-10-11 · 전원
- 회의 결정을 문서에 반영했다: **10/23 개발 시작**, 스프린트 없이 각자 로드맵 순서대로 작업한다(문서의 "Sprint 1·2"는 이제 "1·2단계"라고 부른다). 화면 문구는 해요체, 약관은 격식체. 라이트 모드만 지원한다. MVP는 안산시 미용실·네일샵(속눈썹 포함)
- 10.07 회의의 서비스 규정을 정책으로 반영했다. 위약금 3구간(48~24시간 30%, 24~6시간 50%, 6시간 이내 환불 불가), 10분 홀딩, 할인율 10/20/30/40/50%, 할인율별 수수료 10~6%(VAT 별도), 업주 귀책 취소(할인권 3,000원·패널티 5,000원). 기존 "24시간 이내 환불 불가"는 없어졌다. 자세한 건 CLAUDE.md 핵심 비즈니스 규칙과 `docs/feature-spec.md` 맨 위 블록
- 서비스 이름과 브랜드 색·글꼴은 바뀔 수 있다. 화면에 '줍줍'이나 색 코드를 직접 쓰지 않는다(`docs/conventions.md` "화면 문구와 디자인")
- GitHub main 보호 규칙이 켜졌다. PR을 만들면 현동훈이 리뷰어로 자동 지정되고, 머지 버튼은 현동훈만 쓸 수 있다("Merging is blocked"는 정상). 머지된 브랜치는 GitHub에서 자동으로 지워지니, 다음 작업은 새 브랜치로 시작한다
- `.env.local`은 뼈대가 나오면 팀 단톡방으로 전달한다. 받으면 바로 파일로 저장하고 "저장했어"라고 답한다. 그 뒤 메시지는 지운다
- 할 일: 없음. 올려 준 Issue(#12~#23)는 현동훈이 확인하고 답을 달 예정이다. 그동안 화면 흐름 스케치를 계속한다
