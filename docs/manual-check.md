# 손 점검 체크리스트 (사이클 계획 1·2단계 끝, 11/22)

자동 테스트로 볼 수 없는 것(결제사 화면, 실제 기기 알림, 브라우저 뒤로 가기, 실제 간편 로그인)과 역할 한 바퀴를 사람이 직접 본다. 회귀 시나리오(`docs/test-scenarios.md`)의 🖐 줄과 같다. 결과는 nnoinn이 Claude에게 알려 주면 시나리오 표에 날짜와 함께 적는다.

- 장소: `https://toori.kr`(개발 DB, 포트원 테스트 결제). 처음 열 때 팀 접속 코드를 넣는다
- 계정: 각자의 진짜 카카오·구글 계정(시드 계정은 로그인할 수 없다). 원장님 샵이 없으면 `npm run scenario -- owner-shop approved`로 만든다
- 테스트 결제는 실제 돈이 나가지 않는 포트원 테스트 모드다. 결제 뒤 바로 취소해서 환불까지 본다

| # | 시나리오 | 할 일 | 확인할 것 | 결과 |
| --- | --- | --- | --- | --- |
| 1 | AUTH-07 간편 로그인 | [첫 화면](https://toori.kr/)에서 고객으로, 다시 원장님으로 카카오·구글 로그인 | 각각 들어가지고, 로그인 버튼의 "최근 로그인" 표시가 맞다 | ✅ 11/22 카카오·네이버·구글 모두 됨. 카카오·네이버는 한 로그인으로 묶이고 구글은 따로(번호 인증을 넣을 때 같은 번호 계정을 합친다) |
| 2 | AUTH-08 로그아웃 | 로그인한 채로 [내 정보](https://toori.kr/me)에서 로그아웃 → 브라우저 뒤로 가기 | 첫 화면이 새로 열리고, 뒤로 가도 로그인한 화면이 다시 보이지 않는다 | ✅ 11/22 뒤로 가면 로그인 없이 둘러보는 홈, 내 정보는 로그인으로 |
| 3 | FLOW-06 실제 결제·환불 | [고객 홈](https://toori.kr/home)에서 매물을 골라 [예약하기] → 결제창에서 테스트 결제 → [내 예약](https://toori.kr/reservations)에서 취소 | 결제 완료 화면, 예약 확정 알림, 위약금 구간대로 환불 금액, 포트원 콘솔의 취소 내역 | 고칠 것 11/22: 결제 중 막대가 흰색이라 잘 안 보임(위치·모양 다시), [그만두기] 확인 창의 [계속 결제하기]가 결제 화면으로 가 버림(창만 닫혀야). 현동훈이 고친다 |
| 4 | FLOW-07 웹 푸시(PC·폰) | PC와 폰 각각 [내 정보](https://toori.kr/me)의 알림 설정에서 푸시 알림 켜기 → 다른 계정으로 내 샵 매물 예약 | 기기에 알림이 뜨고, 누르면 그 예약 화면이 열린다(원장님·고객 모두) | 고칠 것 11/22: PC 푸시는 옴. PC 고객 계정에서 화면 안내가 안 뜸(아이패드는 뜸), 아이패드 홈 화면 앱은 푸시가 안 옴, 알림 종 숫자·화면 안내가 새로 고쳐야 나옴(실시간으로). 현동훈이 고친다 |
| 5 | 역할 한 바퀴 | 원장님으로 매물 등록 → 고객으로 예약·결제 → 원장님 [대시보드](https://toori.kr/owner)에서 방문 처리 → 운영자 [입구](https://toori.kr/admin/login)로 들어가 그 예약·샵 정산·기록 보기 | 세 역할 화면의 상태·금액·알림이 서로 맞고, 이상한 점이 없다 | 고칠 것 11/22: 고객 시간대 상세에서 두 번째 서비스를 눌러도 고른 것으로 안 보이고, 고른 서비스로 안 되는 시각이 막히지 않음. 원장님 방문 처리·운영자 화면은 현동훈이 확인. 현동훈이 고친다 |

이상한 점을 찾으면 화면 주소와 사진을 Claude에게 주면, 손 점검에서 나온 것은 담당자에게 넘기지 않고 현동훈이 고친다(11/22 nnoinn).
