# 투리 로고

2026-10-28 확정. 한눈에 보기: [brand-preview.png](brand-preview.png)

## 로고

- 로고는 글자 `toori` 하나예요. 따로 그린 기호는 없어요.
- 글꼴은 **Fredoka SemiBold(600)**이고, 너비와 자간은 기본값이에요.
  - Fredoka는 SIL Open Font License라서 로고에 써도 돼요.
- **i 점**은 브랜드 초록 동그라미예요.
  - 크기는 글꼴 원래 점의 110%예요.
  - 몸통과의 틈은 원래의 70%이고, 몸통 한가운데 위에 있어요.
- **앱 아이콘**은 둥근 모서리 칸 안에 같은 글자 로고를 넣은 거예요.
  - 모서리는 한 변의 22.37%예요.
  - 글자 폭은 칸의 68%예요.
- 로고 파일의 글자는 도형(윤곽)으로 바꿔 두었어요. Fredoka가 없는 기기에서도 똑같이 보여요.

## 색

| 색 | 코드 | 쓰는 곳 |
| --- | --- | --- |
| 검정 | `#111111` | 라이트 모드 글자, 다크 모드 앱 아이콘 바탕 |
| 흰색 | `#FFFFFF` | 다크 모드 글자, 라이트 모드 앱 아이콘 바탕 |
| 초록 | `#10B981` | i 점(두 모드 모두). 앱의 브랜드 초록(`primary`)과 같은 색 |

## 화면에 넣기(코드)

화면에는 공통 UI **`Logo`**(`src/components/ui/logo.tsx`)를 써요.

```tsx
import { Logo } from '@/components/ui/logo';

<Logo className="h-7" />; // 크기는 높이로 정한다
```

- 글자는 둘레 글자색을 따라요. 흰 글자가 필요하면 `className="h-7 text-white"`처럼 써요.
- i 점은 언제나 브랜드 초록이에요.
- 화면 읽기 프로그램에는 서비스 이름(`SITE_NAME`, "투리")으로 읽혀요.
- 로고를 넣으려고 글자 `toori`를 직접 쓰거나 이미지 파일을 새로 만들지 않아요.
- 지금 로고가 들어간 곳은 두 군데예요.
  - 고객 PC 위쪽 메뉴(`CustomerTopNav`)
  - 원장님·운영자 메뉴 머리(`SideNav`)
- 브라우저 탭 아이콘과 홈 화면 아이콘은 `src/app/`의 아래 파일이 맡아요. Next.js가 저절로 `<head>`에 넣어요.
  - `favicon.ico`
  - `icon.svg`: 브라우저가 다크 모드면 검정 칸으로 바뀌어요
  - `apple-icon.png`
- PWA 아이콘은 `src/app/manifest.ts`에 있어요.

## 파일(`public/brand/`)

| 파일 | 쓰는 곳 |
| --- | --- |
| `wordmark/toori-wordmark-{light\|dark}.svg`, `-{512\|1024\|2048}.png` | 글자 로고. 투명 바탕이고 여백 없이 잘려 있어요 |
| `app-icon/toori-app-icon-{light\|dark}.svg`, `-{1024…128}.png` | 둥근 모서리 앱 아이콘. 모서리 밖은 투명이에요(발표 자료, 화면 안 표시) |
| `app-icon/toori-app-icon-{light\|dark}-square.svg`, `-square-{1024\|512}.png` | 모서리 없는 정사각형. 앱 스토어와 OS에 올리는 원본이에요(1024는 App Store, 512는 Google Play) |
| `web/favicon.svg`, `favicon.ico`, `favicon-{light\|dark}-{16\|32\|48}.png` | 브라우저 탭 아이콘 |
| `web/apple-touch-icon-{light\|dark}.png` | 아이폰 홈 화면(180) |
| `web/pwa-icon-{light\|dark}-{192\|512}.png` | PWA 아이콘(정사각형, maskable 가능) |
| `sns/` | SNS·로그인 화면 프로필과 배경 이미지(아래 표) |

- `-light` 파일은 밝은 바탕에 써요. 글자 로고는 검정 글자, 앱 아이콘은 흰 바탕이에요.
- `-dark` 파일은 어두운 바탕에 써요. 글자 로고는 흰 글자, 앱 아이콘은 검정 바탕이에요.
- 앱 화면은 라이트 모드만 지원해요. 그래서 앱 안에서는 `-light`(또는 `Logo` 부품)를 써요.
- 홈 화면 아이콘, SNS 프로필처럼 하나만 골라야 하는 곳은 **흰 바탕(`-light`)이 기본**이에요(10/29). 앱 아이콘과 같은 모양으로 맞춰요.

### `sns/` 프로필·배경

- 프로필(`profile-*`)은 정사각형 앱 아이콘과 같아요. 원형으로 잘려도 글자가 잘리지 않아요.
- 배경(`cover-*`)은 바탕색 위 가운데에 글자 로고를 놓은 거예요.
- 파일 이름 끝 숫자는 그림 크기(픽셀)예요. 서비스마다 권하는 크기에 맞췄어요. 큰 그림을 올리면 서비스가 알아서 줄이니, 맞는 크기가 없으면 `profile-light-1080.png`를 올려요.
- SNS에는 흰 바탕(`-light`)을 써요.

| 파일 | 쓰는 곳 |
| --- | --- |
| `profile-{light\|dark}-640.png` | 카카오톡 채널 프로필(권장 640×640) |
| `profile-{light\|dark}-1080.png` | 인스타그램, 스레드, 카카오톡 오픈채팅 등 정사각형 프로필 |
| `profile-{light\|dark}-400.png` | X(트위터) 프로필 |
| `profile-{light\|dark}-512.png` | 카카오 디벨로퍼스 앱 아이콘(카카오 로그인 동의 화면에 보임, 250KB 미만) |
| `profile-{light\|dark}-120.png` | 구글 로그인 동의 화면 앱 로고(120×120) |
| `cover-{light\|dark}-1500x500.png` | X 헤더 |
| `cover-{light\|dark}-1600x900.png` | 카카오톡 채널 브랜드 카드(가로 16:9), 그 밖의 가로 배너 |
| `cover-{light\|dark}-1280x640.png` | 깃허브 저장소 대표 이미지(Settings → Social preview) |
| `cover-{light\|dark}-1200x630.png` | 링크 미리보기 이미지. 앱은 `src/app/opengraph-image.png`(라이트)를 써서, 카톡에 링크를 붙이면 이 그림이 보여요 |

## 쓰는 규칙

- 비율 그대로 써요. 늘리거나 누르지 않아요.
- 색을 바꾸지 않아요.
  - 글자는 검정 또는 흰색만 써요.
  - i 점은 언제나 초록이에요.
  - 초록 바탕 위에는 쓰지 않아요. i 점이 안 보여요.
- 그림자, 테두리, 기울이기 효과를 넣지 않아요.
- 로고 둘레에는 i 점 지름만큼 이상 비워 둬요.
- 화면에서 글자 로고는 가로 72px 이상으로 써요.
  - 16px 파비콘에서는 글자가 거의 안 읽혀요.

## 만든 방법(참고)

- 글자 윤곽은 Fredoka 600을 글자 크기 1000px로 그려서 땄어요.
- 원래 글꼴 렌더링과 픽셀 단위로 겹쳐 차이가 없음을 확인했어요.
- PNG는 이 SVG에서 뽑았어요.
