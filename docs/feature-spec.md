# 기능 명세

원본은 노션 CORE의 '기능 명세 통합본'이다(2026-10-11 기준). 명세가 바뀌면 nnoinn이 이 파일을 갱신한다. 팀원은 직접 고치지 않는다.

- PWA 웹을 먼저 만들고, 완성되면 앱 UI로도 구현한다.
- 우선순위는 P0 > P1 > P2 순이다.
- ID 앞글자: C 고객(수요자), S 공급자(업주), X 공통 시스템, A 관리자, H 부가기능
- 담당자별 역할과 작업 폴더는 [CLAUDE.md](../CLAUDE.md)의 팀 표를 본다.
- 위약금·수수료·쿠폰·업주 귀책 취소 같은 서비스 규정의 자세한 계산과 예시는 노션 CORE '서비스 규정에 관한 내용'에 있다. 레포에서는 CLAUDE.md "핵심 비즈니스 규칙"과 [tech-guide.md](tech-guide.md) "7. 결정 필요 목록"에 정리되어 있다. 숫자는 모두 정책 설정값으로 둔다.
