# 기능 명세

원본은 노션 CORE의 '기능 명세 통합본'이다(2026-10-05 기준). 명세가 바뀌면 nnoinn이 이 파일을 갱신한다. 팀원은 직접 고치지 않는다.

- PWA 웹을 먼저 만들고, 완성되면 앱 UI로도 구현한다.
- 우선순위는 P0 > P1 > P2 순이다.
- ID 앞글자: C 고객(수요자), S 공급자(업주), X 공통 시스템, A 관리자, H 부가기능
- 담당자별 역할과 작업 폴더는 [CLAUDE.md](../CLAUDE.md)의 팀 표를 본다.

> **10.07 회의로 바뀐 내용 (아래 표보다 우선한다)**
> 노션 CORE '서비스 규정에 관한 내용'에서 확정됐고, 노션 기능 명세에 반영되면 이 블록을 지운다. 숫자는 모두 정책 설정값으로 둔다.
>
> | ID | 바뀐 내용 |
> | --- | --- |
> | C-305, X-202 | 위약금 3구간: 남은 시간 24시간 이상 30%(70% 환불), 6시간 이상 24시간 미만 50%(50% 환불), 6시간 미만 100%(환불 불가). 결제 직후 무료 취소 유예 없음 |
> | C-308 | 환불 불가 구간이 "24시간 이내"에서 **"6시간 미만"**으로 바뀜. 뱃지는 이 구간에만. 상세 화면에 "지금 취소하면 N% 환불" 표시는 넣지 않음 |
> | C-402 | 환불 규정을 여기서 명확하게 보여줌. 동의 문구에 "임박 특가 상품이라 결제 직후에도 무료 취소가 되지 않는다"는 내용을 넣음 |
> | C-404, X-304 | 결제 잠금 "3~5분" 대신 **10분 홀딩**(KTX 방식): 상세 화면에서 '예약하기'를 누르는 순간 시작, 다른 고객은 그 매물을 결제할 수 없음, 화면 오른쪽 위에 10분 타이머. 한 사람당 동시에 1개, 홀딩 중 매물은 목록에 "다른 고객이 결제 중" |
